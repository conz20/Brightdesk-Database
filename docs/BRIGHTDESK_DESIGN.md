# Brightdesk Database — approved design brief

Follow this brief and the canonical [Brightdesk visual standard](https://github.com/connormolloy12/Brightdesk-suite/blob/main/docs/BRIGHTDESK_VISUAL_STANDARD.md) and [machine-readable design contract](https://github.com/connormolloy12/Brightdesk-suite/blob/main/docs/BRIGHTDESK_DESIGN_CONTRACT.json). Brightdesk-AI mirrors this approved contract and includes it in code proposals and independent reviews.

## Shared shell

- Workspace canvas `#F3F6FA`; white work surfaces `#FFFFFF`; muted surface `#F8F9FB`.
- Deep navy navigation gradient `#14233F` to `#0D1930`; white primary labels; muted `#A8B6D0` secondary labels.
- Ink `#202B3C`, body text `#354256`, muted text `#68778C`, borders `#DFE4EC` and `#EBEFF4`.
- Inter/system sans-serif typography, consistent spacing/control sizes, restrained shadows and visible keyboard focus.

## Product identity

- Approved accent `#8058B3`; strong `#63418F`; soft `#F4EFFA`.
- Original icon: `src/branding/icons/database.svg`.
- Approved concept preview: `src/branding/previews/database.svg`.
- Use the accent for product actions/focus only. Keep shared surfaces consistent. Use the original SVG; never use emoji, Unicode pictographs, initials or generic placeholders as the app icon.

## Accessibility and evidence

Use semantic labels and keyboard-accessible controls, visible focus, sufficient contrast, non-colour status cues, reduced-motion support and responsive layouts without clipping essential controls. Concept artwork is not a screenshot. Only publish screenshots captured from a current running desktop build after its workflow is checked.
